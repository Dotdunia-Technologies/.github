# Security Policy

## Reporting a security issue

If you discover a security vulnerability in a public Dotdunia Technologies repository, please do not disclose it publicly through an issue.

Please report security concerns privately to:

**help@dotdunia.com**

Include:

- Repository or project name
- Description of the issue
- Steps to reproduce
- Potential impact
- Screenshots or supporting information where applicable

We will review legitimate reports and respond as soon as reasonably possible.

Please do not attempt to access, modify or disrupt data that does not belong to you while investigating a potential vulnerability.

## Supported projects

Security support applies to actively maintained public repositories owned by Dotdunia Technologies.

Client repositories and private projects are handled separately through their respective support agreements.
