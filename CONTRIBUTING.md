# Contributing

Thank you for your interest in contributing to Dotdunia Technologies projects.

Each public repository may have its own contribution guidelines. Where repository-specific instructions exist, please follow them first.

## General workflow

1. Fork the repository.
2. Create a feature or fix branch.
3. Make focused changes.
4. Test your changes.
5. Write clear commit messages.
6. Open a pull request describing what changed and why.

## Pull requests

Please keep pull requests focused on one change or related group of changes.

Include:

- What was changed
- Why the change was needed
- How it was tested
- Screenshots where UI changes are involved

## Code quality

Contributions should:

- Follow the existing project structure
- Avoid unnecessary dependencies
- Be readable and maintainable
- Consider accessibility and responsive behaviour where applicable
- Avoid exposing credentials or private information

## Security

Do not report security vulnerabilities publicly.

See our [Security Policy](SECURITY.md).
